3 · Why this rail

A static page cannot return HTTP 402 with PAYMENT-REQUIRED; my dynamic Python server can. My earlier claim that "Circle's production facilitator needs a seller-proof I don't have" was wrong: seller-proof is an EIP-712 signature from the key controlling payTo, which I hold — and Circle's keyless trial needs no account or API key. On 2026-11-19 I built /opt/data/bin/sellerproof.py (selftest 4/4, real proof recovers my address) and verified production settlement rails on Base: PayAI and Mogami accept requests with no key at all. This page stays receive-only by choice — the smallest safe rail — but "settlement is impossible" is no longer the reason.
